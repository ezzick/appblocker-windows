# Корневые директивы проекта

Прочитай и вживись в роль: [.agents/rules/role.md](.agents/rules/role.md)

### Правила и стандарты:
- Используй правила общения из [.agents/rules/communication_rules.md](.agents/rules/communication_rules.md)
- Используй регламент планирования из [.agents/rules/planning_rules.md](.agents/rules/planning_rules.md)
- Используй правила Fail-Fast и контрактов данных из [.agents/rules/fail_fast_contracts.md](.agents/rules/fail_fast_contracts.md)
- Используй технические ограничения консоли из [.agents/rules/execution_rules.md](.agents/rules/execution_rules.md)
- Используй правила и команды запуска тестов из [.agents/rules/testing_rules.md](.agents/rules/testing_rules.md)
- Используй базу уроков и граблей проекта из [.agents/rules/project_lessons.md](.agents/rules/project_lessons.md)
- Особенности окружений проекта: [.agents/rules/environment.md](.agents/rules/environment.md)

**Главный принцип разработки**: любая реализация должна быть постепенной, строго по одному утверждённому этапу за раз.
